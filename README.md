# Let's Hang Out

Public voting hub, upcoming hangouts, and pull-up page for [Let's Hang Out](https://www.youtube.com/@LetsHangout_sa).

Live site: https://qyvn.github.io/letshangout/

- `#vote` — suggest the next hangout and vote
- `#upcoming` — the hangouts that are on (Johannesburg time)
- `#pullup` — confirm you're coming
- `#pullup?event=<id>` — pull up to a specific hangout
